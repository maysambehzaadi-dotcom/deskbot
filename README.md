# DeskBot (ربات میز کار)
عامل اجرایی هوشمند، چندمنظوره و مستقل برای کنترل کاملاً پس‌زمینه ویندوز و اندروید بدون اشغال ماوس و کیبورد.

## ساختار پروژه
- **`server/`**: رله و کنترل‌کننده مرکزی (FastAPI + WebSockets) روی پورت `4001`
- **`clients/windows/`**: کلاینت سبک ویندوز با قابلیت اجرای شل، دسترسی به فایل‌ها و اتوماسیون UIA بدون مزاحمت برای کاربر
- **`clients/android/`**: پل ارتباطی با دستگاه‌های اندرویدی (ADB / Shizuku / Accessibility)
- **`docs/`**: مستندات فنی و پروتکل دستورات
